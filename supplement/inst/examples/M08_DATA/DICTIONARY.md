# M08 output dictionary

All outputs are deterministic synthetic teaching calculations. A confidence interval repeats the stated experiment; a credible interval conditions on observations and the declared prior. Neither is a diagnostic threshold. Empty finite-count information is represented by infinite endpoints. Student scale is not SD.

| File | Columns | Meaning and units |
|---|---|---|
| conditional-item-confidence.csv | `lower`, `upper`, `null_p`, `first`, `second` | Fixed latent change in known unit-logistic metric; inclusive conditional null p is a sampling tail. |
| curvature-sensitivity.csv | `curvature_bound`, `posterior_mean_midpoint`, `confidence_lower`, `confidence_upper`, `credible_lower`, `credible_upper` | Curvature score points/year squared; midpoint locations/intervals in score points. |
| gaussian-latent-change.csv | `mean_change`, `variance_change`, `decline_probability`, `new_difference_variance`, `negative_new_difference_probability` | Anchored latent score units and squared units; new noisy difference adds18variance units. |
| item-coordinate-confidence.csv | `occasion`, `lower`, `upper` | Fixed occasion state in known unit-logistic metric; allocated simultaneous coordinate intervals. |
| joint-comparisons.csv | `first`, `retest`, `expected_retest`, `difference`, `standardized_difference`, `innovation`, `standardized_innovation`, `marginal_rule_conditional_error`, `conditional_rule_error` | Scores/differences are raw score points; standardized quantities are dimensionless; conditional errors are probabilities at fixed baseline. |
| known-item-posterior-refinement.csv | `sigma`, `rho`, `order`, `evidence`, `mean_change`, `lower`, `upper`, `decline_probability`, `expected_total_difference`, `negative_new_total_probability`, `quadrature_evidence` | sigma/rho define state prior; contrast moments/quantiles in latent units; expected total difference in item-score units; remaining probabilities/evidence dimensionless. |
| noncompletion-entire-set-confidence.csv | `plugin_lower`, `plugin_upper`, `confidence_lower`, `confidence_upper` | Probability difference; plug-in identified-set bounds and finite whole-set confidence enclosure using full assigned denominators. |
| noncompletion-exact-means.csv | `missing_assumption`, `mean_effect` | Average-effect posterior means in probability difference units; missing-outcome restrictions/prior assumptions separately labeled. |
| personal-slope-sensitivity.csv | `coefficient`, `estimate`, `confidence_lower`, `confidence_upper`, `posterior_mean`, `student_df`, `student_scale`, `credible_lower`, `credible_upper`, `model`, `residual_quadratic`, `mean_variance` | Slope points/year; Student scale in the same units; residual quadratic and noise variance in squared score units. |
| proxy-independent-prior.csv | `target`, `posterior_mean`, `posterior_variance` | Premorbid/current-change coordinates with stated independent original-coordinate prior; means in points and variances in squared points. |
| proxy-operational-bias-prior.csv | `bias_sd`, `mean_change`, `variance_change`, `lower`, `upper` | Change in points; operational-coordinate independent bias changes variance, retaining its own full prior. |
| randomized-average-effect.csv | `mean_effect`, `lower`, `upper`, `positive_probability` | Difference in two binary favorable-outcome population probabilities; posterior probability is not individual benefit. |
| scalar-offset-joint-update.csv | `coefficient`, `estimate`, `confidence_lower`, `confidence_upper`, `posterior_mean`, `student_df`, `student_scale`, `credible_lower`, `credible_upper` | Indices1/2 are calibration intercept/slope; index3 is case conditional mean offset. |
| scalar-reference-coefficients.csv | `coefficient`, `estimate`, `confidence_lower`, `confidence_upper`, `posterior_mean`, `student_df`, `student_scale`, `credible_lower`, `credible_upper` | Coefficient index 1 is intercept,2 is baseline slope; intervals target coefficients. |
| scalar-retest-prediction.csv | `fitted_mean`, `leverage`, `prediction_lower`, `prediction_upper`, `posterior_predictive_mean`, `student_df`, `student_scale`, `predictive_lower`, `predictive_upper` | New observed retest prediction with leverage plus observation noise; score units. |
| serial-equivalence-family.csv | `rho`, `stable_total`, `state_variance`, `noise_variance`, `lag1`, `lag2`, `lag3` | Population component variances and lag covariances under observationally equivalent three-visit laws; rho is dimensionless. |
| state-finite-confidence.csv | `visits`, `people`, `directions`, `common_variance_lower`, `common_variance_upper`, `noise_upper`, `stable_upper`, `trait_share_upper`, `necessarily_empty` | Score-variance bounds and dimensionless share bound; analytic conservative whole-set outer summaries, not exact attained extrema. |
| state-sample-covariance.csv | `visit1`, `visit2`, `visit3`, `visit4` | Fitted four-visit sample covariance, squared score units. |
| trial-entire-set-confidence.csv | `average_lower`, `average_upper`, `benefit_set_lower`, `benefit_set_upper` | Population probability difference and whole benefit-set enclosure from allocated binomial error. |
| unlearned-coupling-refinement.csv | `coupling_a`, `coupling_b`, `order`, `mean_benefit`, `lower`, `upper` | Benefit fraction under a specified unlearned beta coupling prior; approximate midpoint quadrature; not learned cross-world pairing. |

Numerical methods, priors, experiment-specific confidence domains and limitations are explained in [the M08 guide](../M08_GUIDE.md). `order` records a deterministic quadrature resolution. Comparing two orders is a diagnostic, not a certified error bound. Data must be regenerated with the matching public scripts rather than copied from a prior posterior summary.
